# Volley 3D Mobile V2.3 — 正規球場規格版

可直接部署到 GitHub Pages 的手機瀏覽器 3D 排球遊戲（單一 `index.html`）。

## V2.3 新增：18 × 9 公尺排球場

- 球場全長 **18 公尺（z = −9 至 +9）**、全寬 **9 公尺（x = −4.5 至 +4.5）**，中央中線 z = 0。
- **兩側都是 9 × 9 公尺**，白色邊線、端線、中心線與攻擊線線寬約 5 公分。
- 前排的**三米攻擊線位於 z = ±3m**，由中央球網往各隊場區內退 3 公尺。前場三米區有淡色區分。
- 網寬按場寬改為 9m，網高採 **2.43m（男子成年比賽高度）**，網柱在兩側邊線外。
- 發球員站位移到端線外（z 約 ±9.75），**離端線至少 0.30m** 的遊戲操作餘量，保留站發、跳發，以及從線外起跳越線擊球規則。
- 球落地、壓線、出界和回合得分改用新場地邊界。球體有任一部分碰到界線就算界內。
- 2v2 和 6v6 全部重設站位。6v6 三名後排在三米線後、三名前排在三米線內；輪轉後隨之變更站位。
- 調整 AI 接球：給予約 **0.12 秒反應時間**，接球移動速度改為 **5.65 遊戲單位/秒**（玩家搖桿速度為 5.5）。網前攔網仍可較快移動。
- 自動扣球和發球改為比較對方前區、中區、深區多個可能落點，而非每次固定打向同一深度，增添短球與深球變化。
- 原本球路虛線與落點圈、長按滑動選擇扣球方向、AI 攔網與救球等功能沿用。

**規則界線：** 這版把三米線的**幾何位置及前後排陣形**做好，但六人制目前仍屬娛樂簡化玩法，尚未完整加入後排球員三米線內高於網頂進攻違例、前後排站位重疊、自由人等正式規則。角色與排球為提高手機辨識及操作容錯，並非所有模型部位皆依真實比例縮放。

## 遊戲模式

- 2v2：玩家 + 1 名友方 AI 對抗 2 名 AI，先拿 11 分且需領先 2 分。
- 6v6：玩家 + 5 名友方 AI 對抗 6 名 AI，先拿 25 分且需領先 2 分。
- 奪回發球權才輪轉；如果發球員不是玩家，會由對應 AI 發球。

## 操作

- 左邊搖桿：跑位。
- 右側三顆圓形按鈕：撲接、跳躍、擊球。
- 發球：按「拋球」，可先「跳躍」再「擊球」，也可不跳直接擊球。
- 第三觸扣球：短按自動瞄準；長按擊球並滑動，放開後向預覽位置扣殺。
- 接球或托球：按擊球後球碰到角色模型即可成功；低球可撲接。
- 右上角「輔助」可切換預測軌跡＋落點圈／僅落點圈／關閉。

## 部署

把壓縮檔中的 `volleyball3d/index.html` 放到 GitHub Pages 專案根目錄，覆蓋舊檔 Commit。測試新部署可附上 `?v=23` 以避開舊版快取。
