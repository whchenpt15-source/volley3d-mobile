# 🏐 Volley 3D Mobile V1.1 — 修正版

手機單機 3D 排球：1 名玩家 + AI 隊友，對抗 2 名 AI 對手。**以手機橫向、觸控操作為主**。

## V1.1 修正內容

1. **搖桿角色不動**：修正 `moveActor()` 的位移門檻。原本每幀移動距離小於 0.12，常被誤判為不需要移動；現在即使是小位移也會更新角色座標。
2. **攝影機太遠**：由固定的遠距俯瞰鏡頭改成從玩家背後跟隨的第三人稱鏡頭。鏡頭會隨玩家左右、前後移動。
3. **二次觸球／連擊規則**：讓同隊可依序完成第一觸接球、第二觸托球、第三觸進攻；AI 可以追擊接球後傳給他的球。追蹤上一位觸球球員，避免同一人連續擊球。第四次觸球判對方得分；攔網不計入三次觸球並允許攔網者後續擊球。
4. **球路更可預期**：接球與托球的球路會瞄準隊友預計擊球的位置；AI 追蹤球下降到可以接球的攔截位置，而非只追球落地位置。
5. **發球難度**：調整發球初速，減少開球直接飛出底線。

## 用手機更新 GitHub Pages

1. 下載原型 ZIP 並在 iPhone 的「檔案」App 解壓縮，或者直接下載 `index.html`。
2. 在 Safari 登入 GitHub，開啟**你已經建立的遊戲 Repository**。
3. 使用 **Add file → Upload files**，把新的 **`index.html`** 上傳到**儲存庫根目錄**（與原本的 `index.html` 同一位置）並提交變更，讓它取代舊版。若 GitHub 的上傳介面無法直接取代舊檔，可先在 GitHub 中刪除舊的 `index.html`、提交刪除，再上傳新版。
4. 保留原本 Repository 的 **Settings → Pages → Deploy from a branch → main / (root)** 設定，不必重新建網站。
5. 等 Pages 部署完成後，用原本的網址開啟，例如 `https://你的帳號.github.io/你的repository/?v=11`，避免 iPhone Safari 讀取舊版快取。

注意：**不要把 ZIP 原封不動上傳**。必須上傳 ZIP 裡面的 `index.html`。程式會從 jsDelivr 載入 Three.js，初次使用需連線。

## 手機操作

- **左下搖桿**：移動角色，往上推＝向球網前進、往下推＝退後、左右推＝左右移動。
- **接球**：通常在第一觸使用。
- **托球**：通常在第二觸使用。
- **扣殺**：按住蓄力，放開擊球。上方拖曳控制擊球方向。
- **跳躍**：跳躍，靠近球網時可嘗試攔網。
- **黃色提示框**：系統對當下動作的提示，並非強制指令。
- 比賽採**先 11 分且領先 2 分**的簡化休閒規則。

## 測試狀況與限制

- 已通過 JavaScript 語法檢查。
- 已透過自動化瀏覽器環境（以 Three.js 模擬替身）測試觸控搖桿事件能使玩家座標改變、追蹤攝影機定位、同隊第二觸與第三觸合法、AI 避免重複觸球、第四觸違例，並驗證 AI 會接續第二觸／接對手球。
- **尚未在實體 iPhone 的真正 WebGL 3D 繪製環境中驗證畫面與長時間遊玩手感**，請更新後實測並回報問題。三維角色仍是簡單原型模型，並非 Nintendo Switch Sports 的正式美術品質。
- 這是單機網頁遊戲，不涉及帳號、資料庫或多人伺服器。
