# Volley 3D Mobile V1.5 — 手機 3D 排球單機 AI 對戰

這是手機 Safari / Chrome 適用的 2v2 排球遊戲原型：你操控一位球員、另一位 AI 當隊友，對抗兩位 AI。採用網頁 Three.js，不需要登入或後端，但首次進入需要網路載入 3D 引擎。建議橫向操作。

## V1.5 更新

1. **不再讓 AI 搶每一顆第一球**：預測接球落點與可用時間；玩家來得及到達時，優先由玩家接第一球。玩家距離過遠或來不及時，由 AI 隊友補位。接球責任依該次飛行鎖定，避免 AI 每個影格都重新搶球。
2. **明確的 2v2 進攻流程**：第一觸會把球傳向另一位隊友並指定接球位置；第二觸高托球給另一位球員組織第三觸進攻。支援「玩家接 → AI 托 → 玩家扣」與「AI 接 → 玩家托 → AI 扣」。同隊仍最多三次觸球，且不允許同人違規連擊。
3. **發球拋得更高**：上拋初速 5.5 → **6.9** 遊戲單位/秒；從持球高度 1.52 起算，理論最高點約 **2.80 → 3.54** 遊戲高度單位。發球倒數也拉長至 1.75 秒，以配合更長的球路。發球依舊是先按「拋球」、再按「擊球」，且必須站在端線外。
4. **托球再加高**：第二觸傳球目標高度由 **2.72 → 3.15**，規劃飛行時間由 **1.30 → 1.42 秒**；在一組測試條件下，托球拋物線最高點約 5.5。高度和飛行時間取決於擊球當下球的位置。

## 手機操作

- 左側搖桿：自由跑位
- 右側「⬆ 跳躍」：跳躍、網前攔網／起跳扣球
- 右側「🏐 擊球」：依第一、二、三觸自動接球／托球／扣殺
- 發球時：先按「🙌 拋球」，抓好時機再按「🏐 擊球」
- 擊球方向：右側瞄準滑桿

所有打擊依舊依角色手部碰撞判斷；單純球撞到身體不算觸球。

## 更新 GitHub Pages

1. 從 ZIP 解壓縮，取出 `volleyball3d/index.html`，或直接下載單獨的 `index.html`。
2. 將新的 `index.html` 上傳到原本 GitHub Repository 的根目錄，覆蓋舊版本後 Commit。
3. GitHub Pages 部署完成後，手機 Safari 開啟原本網址，在尾端加 `?v=15` 避免讀取舊快取，例如 `https://帳號.github.io/volley3d-mobile/?v=15`。

## 測試與已知限制

- 已進行 JavaScript 語法檢查、Chromium 下的遊戲邏輯模擬測試（以 3D 引擎替身注入、不使用實體 GPU 渲染）：玩家可接時 AI 讓球、遠球 AI 補位、兩種三次觸球組合、AI 實際自動完成第二與第三觸、高拋球，以及 AI 高拋球自動發球。
- 尚未在實際 iPhone Safari / 原始 Three.js WebGL 環境跑完完整比賽；碰撞手感與鏡頭仍可能需實機調整。
- 這是休閒排球原型，不是完整的正式國際排球競賽規則模擬。
