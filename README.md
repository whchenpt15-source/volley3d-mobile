# Volley 3D Mobile V1.4 — 手機 3D 單機排球

這是可以用手機 Safari / Chrome 開啟的 2v2 排球原型。你控制一名球員，另外三名球員由本機 AI 操控。**建議橫向遊玩**，首次開啟需要網路連線以載入 Three.js。

## V1.4 改動

1. **發球拋球更高**：上拋速度從 3.6 m/s 增加至 5.5 m/s，理論拋球最高點由約 2.07 m 升至約 2.80 m。維持「拋球 → 擊球」兩次按鍵與端線外發球規定，右手發球高度一併調整。AI 發球拋球時誤清除速度的問題亦已修復。
2. **托球更高、比較有時間跑位**：第二觸托球目標高度由 2.35 m 調至 2.72 m，規劃飛行時間由 1.05 s 延長至 1.30 s；實際拋物線最高點依接觸高度而變，可能達 4 m 以上。第一觸傳給隊友的球也稍微調高並延長滯空。
3. **接球判定放寬**：玩家第一觸手部有效距離約從 0.57 m 增至 0.67 m（計入球與手的半徑），球高速飛越手部時使用上一影格到當前影格的掃掠碰撞補判；仍必須接近手部、按下擊球鍵且處在有效揮手時間內。扣殺、攔網維持較精準的判定，不改成身體碰到就算接球。

## 操作

- 左側虛擬搖桿：控制跑位
- 右側「⬆ 跳躍」：跳躍、網前攔網
- 右側「🏐 擊球」：依目前情境接球／托球／扣殺
- 發球時：先按「🙌 拋球」，球上拋後再次按「🏐 擊球」；發球者不能踩進端線
- 右側滑桿：調整進攻方向

## 更新 GitHub Pages

將 `volleyball3d/index.html` 上傳至你的原有 GitHub Repository **根目錄**，取代舊版 `index.html`，Commit 後等待 Pages 完成部署。Safari 開啟網址時把參數改成 `?v=14`，例如 `https://你的帳號.github.io/volley3d-mobile/?v=14`。不要只上傳 ZIP 而不解壓縮。

## 測試與注意事項

- V1.4 經過 JavaScript 語法檢查及 Chromium / Three.js 替身模擬：玩家雙擊發球、AI 自動發球、接球容錯距離、身體碰球無效、高速球掃掠碰撞、托球拋物線高度，以及連續兩次觸球違例判定。
- 尚未完成真實 iPhone Safari 搭配原始 Three.js 的實機效能與手感測試。若手機實際畫面或觸碰反應異常，仍應根據實測再校正。
- V1.4 是休閒排球遊戲原型，非全套正式 FIVB 規則模擬。
