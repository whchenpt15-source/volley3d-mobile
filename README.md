# Volley 3D Mobile V1.2 — 雙按鍵與手部碰撞版

這是手機優先的 3D 單機 2v2 排球原型：你與一名 AI 隊友，對戰兩名 AI。基於 V1.1 改版，可直接用新版 `index.html` 取代 GitHub Pages 上的舊檔。

## V1.2 新增與修正

1. **手部判定**：四位角色都有可見的手與手臂。接球、托球、扣殺與攔網，一律需要排球與手部球體的碰撞判定；排球碰到角色身體本身不算成功觸球。為保持休閒玩法，手部碰撞圈有小幅容錯。AI 也採用相同判定方式。
2. **只有兩個動作鍵**：左手搖桿自由移動；右手只有「跳躍」與「擊球」。「擊球」依同隊目前的觸球次數，自動選擇第一觸接球、第二觸托球、第三觸扣殺。跳到網前並以手部碰到對手來球，會判定攔網。上方仍保留左右擊球瞄準滑桿。
3. **發球機制**：球隊得分後取得發球權；發球員會站在該隊底線外的淺綠區。輪到你發球時，必須在端線外按「擊球」拋球，角色隨後會揮手發球；拋球之後、手部碰球之前踩到端線或進入場內，判對方得分。沒打到球也算發球失敗。AI 會在底線外自動發球。
4. **AI 揮手與跑位**：修正 AI 揮手時轉向跑動方向而接不到球的問題；增加簡易 AI 網前攔網意圖。
5. **保留 V1.1**：手機橫向第三人稱跟隨鏡頭、虛擬搖桿、同隊 3 次觸球規則、同一球員不得連續碰球（攔網例外）、11 分領先 2 分獲勝。

## iPhone 使用與更新 GitHub Pages

1. **直接使用 `index.html` 即可**，不需要把 ZIP 上傳到 GitHub。
2. 登入 GitHub，打開你目前的遊戲 Repository，使用 **Add file → Upload files**，把新版 `index.html` 放在儲存庫根目錄並替換舊檔、提交變更。若不能直接覆蓋，就先透過 GitHub 網頁刪除原檔並提交，再上傳同名新檔。
3. Pages 原本的部署設定 `main / (root)` 不需要修改。
4. 發布成功後，在 iPhone Safari 用舊網址加上 `?v=12` 開啟新版本，以降低舊網頁快取干擾。
5. 將 iPhone 轉成橫向，可得到最清晰的球場與雙手操作佈局。

## 操作說明

| 區域 | 功能 |
|---|---|
| 左下方虛擬搖桿 | 角色移動、發球前退到端線外 |
| 右下「跳躍」 | 起跳；網前手碰球可攔網 |
| 右下「擊球」 | 第一觸接球、第二觸托球、第三觸扣殺；發球時一鍵拋球＋揮手擊球 |
| 擊球方向滑桿 | 左右選擇攻擊或發球方向 |

**簡化比賽規則**：攔網不計入 3 次觸球。同隊最多三次觸球，非攔網情況下同一人不得連續觸球。發球時必須在端線外，未碰球或踩線屬發球失誤。本版仍屬遊戲化簡化規則，並非完整正式排球規則模擬。

## 測試與限制

已通過 JavaScript 語法檢查，以及以 Three.js 邏輯替身進行的自動化瀏覽器測試：兩個動作鍵、手機搖桿移動、單手接球、三次觸球、身體不能直接觸球、同球員連擊違例、攔網不計觸球、AI 發球、站在線內不能發球、拋球後踩線失誤。

仍須在真正 iPhone Safari 和真實 Three.js WebGL 環境中測試視覺、幀率與觸球手感。角色是簡易卡通原型，不是正式 3D 動畫角色。Three.js 從 CDN 載入，首次進入頁面需要網路。
