# Volley 3D Mobile V1.8 — 強力扣殺與 AI 失誤

手機橫向瀏覽器玩的 3D 2v2 排球原型：玩家與一名 AI 隊友，對抗兩名 AI。保留 V1.7 的背後攝影機、虛擬搖桿、兩動作鍵、我方/敵方球路與落點提示，以及全角色碰撞擊球判定。

## V1.8 更新

1. **扣殺更快**：當一次合法觸球被判定為第三觸「扣殺」時，啟用專門的高速下墜球路。遊戲內球路下墜加速度為 23.6（一般球路 11.8），並自動計算越網所需的高度。在相同起點／落點的一組測試案例中，扣殺水平速度比 V1.7 的一般球路約快 41%；不同接觸位置的實際增幅不同。球路預測虛線現在同步使用每一球當前的加速度。
2. **AI 有低機率失誤**：每次有效接球／托球／扣殺時，敵方 AI 各有約 4.5% 的失誤機率，隊友 AI 約 2.5%。前兩觸可能漏接，第三觸可能扣出界。一次觸球只判定一次，沒有逐影格反覆抽籤，也不套用到玩家操作。
3. **扣球動畫提升**：扣殺改成引臂蓄力 → 過頭揮臂 → 身體前傾收臂 → 回到預備姿勢，跳起時有腿部姿勢變化。成功扣球會保留收臂動畫，加入短暫金黃色打擊光圈。
4. **快速球過網修正**：以跨越球網平面的實際高度判斷觸網，飛行預測與遊戲更新採相同檢查方式。

## 手機玩法

- 左下：虛擬搖桿移動角色。
- 右下「跳躍」：起跳／網前攔網。
- 右下「擊球」：依我方觸球次數，自動決定接球、托球或強力扣殺。按鍵有效時間內，球碰到角色可見模型就能擊球；攔網仍看手部。
- 發球：站在端線外，先按「拋球」，再按「擊球」。
- 右側滑桿：調整進攻左右方向。
- 右上「輔助」：可選擇虛線＋落點、僅落點、關閉。

## 測試狀態

- `node --check` JavaScript 語法檢查通過。
- 使用 Chromium 和離線 Three.js API 替身進行模擬：扣殺相對球速、實際越網落地與得分、AI 漏接、AI 扣出界、動畫關鍵姿勢與擊球後收臂、兩階段發球，以及飛行預測輔助。
- V1.7 接球碰撞、三次觸球、同人連擊等原有回歸測試也通過。
