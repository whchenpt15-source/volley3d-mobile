# Volley 3D Mobile V2.0 — 圓形動作按鈕與跳躍發球

可在手機瀏覽器玩的 3D 2v2 排球：玩家加上一位 AI 隊友，對抗兩名 AI 對手。基於 V1.9 升級，保留短距離撲接、強力扣殺、AI 少量失誤、接球虛線與落點提示，以及身體模型接球判定。

## V2.0 更新

1. **三個圓形按鈕**：右側改成三顆真正圓形的觸控按鈕，上方「撲接」、左下「跳躍」、右下「擊球」。直向與橫向會自動調整圓形直徑。撲接冷卻狀態也會直接標在圓形按鈕內。
2. **跳躍發球**：輪到玩家發球時，先在端線外按「拋球」，接著可以按「跳躍」，最後在空中按「擊球」。只有排球實際碰到角色模型才會成功，仍需掌握時機。跳發球具有比原本站立發球更快的水平球速。
3. **保留站立發球**：仍可直接以「拋球 → 擊球」發球；站立擊球需要抓球在角色可觸及高度的時機。
4. **端線規則**：跳躍發球必須在端線外起跳；合法起跳後可以在空中跨過端線擊球。站立發球時仍不可踩線。球沒擊中並落地，判發球失誤。
5. **AI 發球維持原樣**：AI 不必使用玩家的跳躍發球，讓原本對戰流程保留。

## 操作方式

- 左側圓形搖桿：移動。
- 右側上方「撲接」：低球救援，按方向搖桿決定撲救方向。
- 右側左下「跳躍」：跳躍、網前攔網；發球拋球後可起跳。
- 右側右下「擊球」：一般回合接球、托球、扣球；輪到我方發球時，第一次顯示「拋球」，第二次顯示「擊球」。
- 右上「輔助」：切換球路虛線與落點圈（完整 / 落點 / 關閉）。
- 桌機測試熱鍵：WASD 移動；空白鍵跳躍；J/K/L 擊球或拋球；F 撲接；P 暫停；R 重來。

## GitHub Pages 更新

1. 解壓 ZIP 將 `volleyball3d/index.html` 上傳到 GitHub Repository 網站根目錄，覆蓋舊版 `index.html`。
2. Commit 並等 GitHub Pages 部署完成。
3. 使用原本網址，Safari 若有快取可在網址加上 `?v=20`。

不需資料庫或後端。遊戲使用 Three.js（由 jsDelivr CDN 提供），首次載入需要網路。

## 測試範圍

- `node --check` 語法驗證。
- 模擬 Chromium 瀏覽器與 Three.js API 替身：三顆圓形觸控按鈕在橫向（844×390）和直向（390×844）尺寸正確；未拋球不能起跳；拋球後能起跳；0.20／0.35／0.56 秒等不同跳發時機能成功擊球；跳發比站立發球速度更高，預測越網且落在對面；合法空中跨線不犯規、站立踩線犯規；AI 發球與撲接救球回歸測試。
- 尚未在真實 iPhone Safari / WebGL 裝置上完整遊玩驗證，需進一步實際測試手感及幀率。
