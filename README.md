# Volley 3D Mobile V1.3 — 3D 手機單機排球

以手機 Safari / Chrome 橫向遊玩為主的 2v2 AI 排球原型。1 名玩家與 1 名 AI 隊友，對抗 2 名 AI 對手。

## V1.3 的三個修正

1. **角色正面維持朝向球網，最多左右各 45 度**：左右、前後跑動不再使角色身體轉向跑動方向；角色在對球做擊球動作時，也被限制於以球網方向為正面、左右各 45° 範圍。藍／橘兩隊互相面對，各自具有自己的正面基準。
2. **修正對方扣球無法過網**：原本扣球使用固定 0.90 秒拋物線，當擊球點較低時往往低於網頂。新版本會依手部實際擊球高度、擊球點與目標落點，計算至少能越過網頂（含排球半徑與額外餘量）的飛行時間，適用於玩家與 AI 的第三次攻擊以及發球。仍然可能被合法攔網，並非所有球都保證得分。
3. **發球按鈕改為「拋球 → 擊球」兩段式**：輪到玩家發球時，原本「擊球」鍵會變成「🙌 拋球」；點擊後球上拋，按鈕顯示「🏐 擊球」，玩家要在球落地前再次按下，角色揮手並藉手部碰球完成發球。站在端線內不能拋球；擊球時踩線或沒打到球屬發球失誤。AI 對手會自動完成拋球與擊球。

## 手機操作

- 左下搖桿：移動（角色仍維持向球網方向）
- 右側「⬆ 跳躍」：跳起；在網前以手攔網
- 右側「🏐 擊球」：接球／托球／扣殺（由局勢自動判定）
- 輪到你發球：「🙌 拋球」→ 球在空中再按「🏐 擊球」
- 右側滑桿：調整進攻左右方向

維持 V1.2 手部碰撞檢查、最多三次觸球、非攔網時禁止同球員連擊與簡化比分規則。這仍然是開發原型，非正式全規則排球模擬。

## 部署到 GitHub Pages

1. 解壓縮 ZIP，找到 `volleyball3d/index.html`（或直接取得原始 `index.html`）。
2. 在你的 GitHub Repository 根目錄，**將舊的 `index.html` 替換為新版**並 Commit；只上傳 ZIP 不會讓 Pages 自動解壓部署。
3. 已啟用的 Pages (`main` 分支、`/(root)`) 不必重新設定。
4. 發布後，在 Safari 用原網址加上 `?v=13` 載入新版本（若原本有 `?v=12`，請改成 `?v=13`）。
5. 首次載入需要網路連線，因 Three.js 引擎從公共 CDN 取得。

## 測試與限制

V1.3 已完成 JavaScript 語法檢查，並在 Chromium 的 Three.js 替身邏輯環境驗證：

- 玩家按兩次才能發球；第一次拋球不會自動揮擊；AI 能自行發球。
- 搖桿控制角色側向移動，面朝方向不會跟著轉到側面；兩隊面向限制都在 ±45° 內。
- 雙方發球、站在不同擊球位置的第三次攻擊，拋物線在球網處具有足夠高度。
- AI 角色以**實際手部碰球**發出的球，在模擬物理更新中可越過球網，未因網子碰撞反彈。

仍需用真實 iPhone Safari / 真實 Three.js 3D WebGL 與實際操作來測試手感、效能、滑桿、動畫及 AI 對戰平衡。發球時機、AI 擊球命中率可能依裝置更新率需要持續調整。
