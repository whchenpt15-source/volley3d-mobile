# Volley 3D Mobile V1.7 — 我方傳球落點與整體模型擊球

這是手機瀏覽器專用的單機 2v2 3D 排球遊戲：1 位玩家 + 1 位 AI 隊友，對抗 2 位 AI 對手。

## V1.7 更新

### 1. 我方接球、托球後也有預測落點
- 對方發球或攻擊飛向我方：延續 V1.6 的 3D 白色虛線和綠／黃／紅落點圈。
- 我方**第一觸接球**後：顯示 3D 預測虛線和**藍色落點圈**，方便 AI 隊友或玩家準備第二觸。
- 我方**第二觸托球**後：顯示 3D 預測虛線和**藍色落點圈**，方便移動準備第三觸攻擊。
- 我方第三觸球已過網：隱藏提示，等對方來球再顯示。
- 右上「輔助」保留「完整／落點／關閉」模式；使用瀏覽器 localStorage 記住選項。
- 落點圈顯示**若無再次觸球，球第一次碰地的預測位置**，不是自動接球位置。球被擊打或觸網後會重新計算。

### 2. 放寬擊球判定
- 玩家按下「擊球」時便立即檢查碰撞，不再等到揮手動畫中段。
- 按下後短暫揮擊期間（約 0.49 秒），只要球接觸角色的**頭、軀幹、腿、手臂或雙手**，即可成功接球／托球／扣球。
- 角色模型碰撞範圍額外放寬約 12 cm；會針對高速球沿前後影格路徑檢查，減少漏判。
- **沒有按擊球時，球碰到身體不會自動成為有效擊球。**
- **攔網**仍依跳躍及手部接觸判定；保留端線外兩段發球、最多 3 次觸球與同一球員不得連續觸球的基本規則。

## 操作（手機橫向最佳）
- 左下虛擬搖桿：移動
- 右下「跳躍」：起跳／網前攔網
- 右下「擊球」：第一觸接球、第二觸托球、第三觸攻擊（須與角色模型接觸）
- 我方發球：站在端線外，按「拋球」，球拋出後再按「擊球」
- 右側滑桿：調整扣球方向
- 右上「輔助」：完整／落點／關閉

## GitHub Pages 更新
1. 下載新版 `index.html`。
2. 開啟原 GitHub Repository，將根目錄舊的 `index.html` 替換並提交 Commit。
3. 完成部署後開啟原遊戲網址，必要時加上 `?v=17` 避免 Safari 快取。

原型以單一 HTML 交付，Three.js 從 CDN 載入，首次遊玩需要網路連線。沒有多人連線與資料庫。
