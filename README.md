# Volley 3D Mobile V2.1

可部署於 GitHub Pages 的單檔手機版 3D 排球遊戲（`index.html`）。

## 玩法

- **2v2 雙人制**：1 名玩家 + 1 名我方 AI，對抗 2 名 AI；先得 11 分並領先至少 2 分獲勝。
- **6v6 六人制**：1 名玩家 + 5 名我方 AI，對抗 6 名 AI；先得 25 分並領先至少 2 分獲勝。
- 主選單可選擇模式；遊戲右上角的 `2v2` / `6v6` 按鈕也能快速切換，**切換中途會重新開始比賽**。
- 球隊**僅在奪回發球權**時輪轉。六人制依 1→6→5→4→3→2→1 的順序輪轉位置；2v2 以兩名球員輪流發球。
- 如果我方輪轉後發球員不是玩家，會由該名我方 AI 自動拋球、擊球；玩家仍負責自己控制的角色。

## 手機操作

- 左側虛擬搖桿：移動。
- 右側圓形 `撲接`、`跳躍`、`擊球` 按鈕。
- 普通觸球：按「擊球」時球碰到角色模組即可成功；撲接時碰到低球能自動救起。
- **第三觸扣殺**：輕點「擊球」使用自動瞄準；**長按約 0.18 秒**顯示黃色箭頭和對方場地的目標圈，上下左右滑動調整落點，**放開後揮擊**。方向調整只作用於扣殺，不影響一般接球／托球／發球。
- **發球**：當玩家位於發球位時，端線外「拋球 → 擊球」可站發；「拋球 → 跳躍 → 擊球」可跳發。發球員是 AI 時玩家按鈕在發球階段不能操作。
- 右上 `輔助` 可切換球路虛線+落點圈、僅落點圈或關閉。

## 規則與限制

- 得分後由得分方發球；**只有換邊取得發球權時，得分方需要輪轉**。
- 保留三次觸球、同人連擊、出界、觸網與手部攔網等遊戲既有判定。
- 六人制為簡化的娛樂版本：已提供 6 個場上位置與輪轉、6 人 AI 攻防分工，但**尚未完整實作自由人、換人、前後排攻擊違例、站位重疊違例、輪替上場及正式比賽的所有規章**。
- 6v6 同場共有 12 名角色，對低階手機的負載高於 2v2。建議橫向操作。
- 3D 模組透過 jsDelivr 動態載入 `Three.js 0.160.1`，初次開啟需要網路連線。
