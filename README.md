# Volley 3D Mobile V1.6 — 3D 球路預測與接球輔助

適用手機 Safari / Chrome 的單機 2v2 排球網頁遊戲。一名玩家 + 一名 AI 隊友，對抗兩名 AI 對手。

## V1.6 新增功能

1. **3D 球路虛線**：對方已把球朝我方半場打來時，畫出未來最多約 1.15 秒的拋物線虛線（18 段）。每秒約重新預測 12 次；實際擊球、網前反彈或球速變化後會在下一次更新時重新繪製。
2. **預測落點圈**：球預計落在我方半場或我方後方界外時，在地板顯示預測位置。球快落地時提示圈逐漸縮小。若球觸網後掉回對面，**不會錯誤顯示我方落點圈**。
3. **接球難度顏色**：綠色＝較容易、黃色＝需跑位、紅色＝難接／可能出界。根據預測球飛到手部高度的時間、玩家位置和移動速度估算；只是提示，不改變球速、AI 或有效碰撞範圍。
4. **三種輔助模式**：點畫面右上角「輔助：完整」可循環切換 **完整 → 落點 → 關閉**，選項會在同一瀏覽器中記住。完整＝虛線與落點圈；落點＝只有落點圈；關閉＝完全隱藏。
5. **長回合修正**：來球與 AI 接球者判斷不再被上一輪未重設的我方觸球次數干擾；上一位觸球者是對方時，才提示我方下一次接球。

> 預測的是球在**不被任何球員再次觸碰**時的預估路線。AI、玩家碰球會改變實際軌跡；預測圈不是必定接得到的保證。

## 手機操作

- **左下搖桿**：移動玩家
- **右下「跳躍」**：跳躍／靠近網前攔網
- **右下「擊球」**：依觸球階段自動使用接球、托球或扣殺動作
- **發球時**：擊球鍵先顯示「拋球」；按一次拋球，再按一次「擊球」揮手發球。角色必須站在端線外
- **擊球瞄準**：右側滑桿左右拖曳
- **右上「輔助」**：完整／落點／關閉

保留 V1.5 的手部觸球判定、兩段式發球、第三人稱鏡頭、AI 接球分工和同隊最多三次觸球的基本規則。

## 更新 GitHub Pages

1. 下載 V1.6 ZIP 並解壓縮，取出 `volleyball3d/index.html`；也可以直接下載單獨的 `index.html`。
2. 在原本 GitHub Repository 中，用新檔案覆蓋根目錄的 `index.html`，並 Commit；**不需要重新建立 Repository**。
3. 等 GitHub Pages 部署完成後，開啟原本網址，結尾加 `?v=16` 避免瀏覽器快取（例如 `https://你的帳號.github.io/volley3d-mobile/?v=16`）。

初次載入需要網路連線，以取得 Three.js CDN 模組。不需要額外後端或資料庫。

## 已測試與限制

- JavaScript 語法檢查通過。
- 使用 Chromium 與離線 3D API 替身的自動化邏輯測試：正常越網軌跡、落點近似數值、觸網反彈、三種顯示模式、我方托球隱藏、長回合接球責任與發球高度皆通過。
- 尚未在真正 iPhone Safari + Three.js WebGL 上進行完整實機對戰、FPS 和視覺測試；實際體感可能需要後續微調。
